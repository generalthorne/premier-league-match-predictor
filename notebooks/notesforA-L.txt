### Experiment B — Remove Goal-Difference Features

**Why suggested:** Test whether the calculated goal-difference features added useful information beyond the underlying goals-scored and goals-conceded statistics.

**Removed:**
- HomeGoalDiff
- AwayGoalDiff
- GoalsScoredDiff

**Results:**
- Accuracy: 50.96%
- Log loss: 1.0218
- Draw precision/recall/F1: 0.00 / 0.00 / 0.00

| | H | D | A |
|---|---:|---:|---:|
| H | 114 | 1 | 36 |
| D | 50 | 0 | 33 |
| A | 55 | 4 | 72 |

**Decision:** Kept without the goal-difference features. Accuracy and log loss both improved over Experiment A.

### Experiment C — Draw Class Weighting

**Why suggested:** The baseline model rarely predicted draws, despite draws representing a substantial part of the dataset.

Tested different draw class weights while keeping the other class weights at 1.00.

| Draw weight | Accuracy | Log loss | Draw precision | Draw recall | Draw F1 |
|---:|---:|---:|---:|---:|---:|
| 1.00 | 50.41% | 1.0300 | 0.00 | 0.00 | 0.00 |
| 1.25 | 49.32% | 1.0323 | 0.25 | 0.06 | 0.10 |
| 1.50 | 47.40% | 1.0405 | 0.20 | 0.12 | 0.15 |
| 1.75 | 42.74% | 1.0542 | 0.22 | 0.31 | 0.26 |
| 2.00 | 40.00% | 1.0677 | 0.23 | 0.47 | 0.31 |

**Decision:** Retained equal class weights (1.00). Higher draw weights increased draw recall but substantially worsened overall performance.
